3D Mouse-Following Effect

The title follows your cursor creating a subtle 3D perspective effect. As you move the mouse, the title rotates in 3D space.

// Track mouse position in hero area
function onMove(e) {
  const rect = hero.getBoundingClientRect();
  const px = ((e.clientX - rect.left) / rect.width - 0.5) * 2;
  const py = ((e.clientY - rect.top) / rect.height - 0.5) * 2;
  targetY = px * 18;
  targetX = py * -12;
}

Scroll Parallax Effect

Portfolio cards and content sections move differently as you scroll, creating depth and visual interest.

// Update scroll effects for cards
function updateScrollEffects() {
  const center = window.innerHeight * 0.5;
  scrollTargets.forEach(el => {
    const rect = el.getBoundingClientRect();
    const normalized = (rect.top - center) / 
      (window.innerHeight * 0.8);
  });
}
